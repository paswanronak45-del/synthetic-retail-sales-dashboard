Synthetic Retail Sales Dashboard
Project Overview
The Synthetic Retail Sales Dashboard is a data analytics project designed to analyze retail sales performance and present important business insights through an interactive dashboard.

The project uses a synthetic retail sales dataset containing order details, product information, sales channels, geographical regions, discounts, revenue, costs, profits, and order statuses. The dashboard helps users understand sales trends, evaluate profitability, compare product categories, and identify sales performance across different regions and channels.

The interactive dashboard includes KPI cards, charts, date filters, dropdown slicers, and a product performance table. Users can apply filters and interact with charts to explore specific aspects of retail sales.
Project Objectives
- Analyze monthly sales trends and overall sales performance.
- Track net sales, total profit, total orders, and profit margin.
- Compare sales performance across product categories and regions.
- Understand the contribution of different sales channels.
- Explore product-level performance using an interactive table.
- Support data-driven decision-making through visual analysis.
Key Features
- KPI Cards: Total Net Sales, Total Profit, Total Orders, and Profit Margin.
- Monthly Sales Trend: Visualizes sales performance over time.
- Product Category Analysis: Compares sales across product categories.
- Regional Sales Analysis: Evaluates sales performance across regions.
- Sales Channel Analysis: Shows the contribution of different sales channels.
- Interactive Filters: Filter data by order date, region, product category, and sales channel.
- Cross-Filtering: Interact with charts and table rows to explore selected data.
- Product Performance Table: View and sort product-level sales information.
- Responsive Design: Dashboard layout adapts to different screen sizes.
Tools and Technologies
- HTML
- CSS
- JavaScript
- Chart.js
- Excel
Dataset
The project uses a synthetic retail sales dataset containing 1,500 sales records. It includes order dates, product categories, regions, cities, sales channels, payment methods, quantities, discounts, sales amounts, costs, profits, and order statuses.

The data is intended for learning, analysis, and demonstration purposes rather than representing actual company transactions.
Project Outcome
This project demonstrates practical skills in data visualization, KPI tracking, sales performance analysis, dashboard development, and interactive data exploration. It provides a foundation for understanding retail business performance and communicating insights through visual analytics.
